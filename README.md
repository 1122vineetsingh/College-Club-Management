# 📚 College Club Management System

A web-based application designed to simplify and streamline the management of college clubs, events, and student engagement.

## 🚀 Overview
The College Club Management System provides a centralized platform where students and administrators can manage club activities, events, and communication efficiently. It enhances collaboration and keeps students updated with all club-related activities.

---

## ✨ Features

- 🔐 User Authentication (Login / Register)
- 👤 Role-based access (Admin / Club Admin / Student)
- 🏫 Club Creation & Management
- 📢 Post & Announcement System
- ❤️ Like, Comment & Share Posts
- 🔖 Save / Bookmark Posts
- 📅 Event Management
- 🔔 Real-time Updates / Notifications
- 📊 Dashboard for personalized updates

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```
git clone https://github.com/1122vineetsingh/College-Club-Management.git
cd College-Club-Management
```

### 2️⃣ Install dependencies
```
npm install
```

### 3️⃣ Setup environment variables
Create a `.env` file and add:
```
PORT=5000
DB_URI=your_database_url
JWT_SECRET=your_secret_key
```

### 4️⃣ Run the project
```
npm start
```
